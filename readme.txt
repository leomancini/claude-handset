Project Name: Claude Handset
Project Version: #3cf75256
Project Url: https://www.flux.ai/leomancini/claude-handset~2m

Project Description:
60 mm circular USB-C composite Audio + boot-compatible HID board with an onboard Knowles SPH0641LU4H-1 PDM MEMS microphone, MAX98357A amplified differential output for an 8 Ω speaker, and two separated diagonal side-actuated F13/F14 buttons.
