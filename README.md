# Claude Handset

60 mm round USB-C handset board: RP2040, MAX98357A speaker amp, Knowles PDM microphone, two
side buttons that send F13/F14 as a boot-compatible HID keyboard, all in one USB composite device.

Designed in [Flux](https://www.flux.ai/leomancini/claude-handset~2m). This repo holds the
hand-patched manufacturing files that were sent to JLCPCB (order 10211669A, September 2026),
the verification tooling, the enclosure STLs, and the ordering notes.

**Start with [CLAUDE.md](CLAUDE.md)** for the full hardware description, pin map, and firmware plan.
